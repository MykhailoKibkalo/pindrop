# 🚀 Швидкий старт — збірка Pindrop на своєму Mac

Короткий гайд, як зібрати й запустити цей форк Pindrop із вихідного коду. Розрахований
на ~15 хвилин (без урахування першого завантаження моделі). DMG не потрібен —
застосунок збирається й запускається локально.

> Цей форк додає **українську мову** (інтерфейс + диктовка), покращений переклад,
> багатомовний AI-промпт і фікс зависання на завантаженні моделі.

---

## 1. Передумови

| Інструмент | Навіщо | Як поставити |
|---|---|---|
| **macOS 14+** (Sonoma/Sequoia) | цільова платформа | — |
| **Apple Silicon** (M1+) | модель рахується на Neural Engine | — |
| **Xcode 15+** + Command Line Tools | компіляція | App Store, потім `xcode-select --install` |
| **Homebrew** | менеджер пакетів | [brew.sh](https://brew.sh) |
| **just** | обгортка команд збірки | `brew install just` |
| ~5 ГБ вільного місця | модель Whisper (~3 ГБ) + збірка | — |

Перевірити, що все на місці:

```bash
xcodebuild -version      # має показати Xcode 15+
just --version
```

---

## 2. Клонування

```bash
git clone https://github.com/MykhailoKibkalo/pindrop.git
cd pindrop
```

Уся актуальна робота вже в гілці `main` — додаткових перемикань не треба.

---

## 3. Збірка та запуск

### Варіант А — через Xcode (найнадійніший)

Цей шлях коректно налаштовує підпис і дозволи (мікрофон, Accessibility).

1. Відкрий проєкт:
   ```bash
   just xcode      # або: open Pindrop.xcodeproj
   ```
2. У Xcode обери таргет **Pindrop** → вкладка **Signing & Capabilities**.
3. Увімкни **Automatically manage signing** і вибери свою **Team**
   (підійде безкоштовний особистий Apple ID — «Personal Team»).
   > ⚠️ У репозиторії прописана чужа команда розробника — її треба замінити на свою,
   > інакше збірка впаде з «No signing certificate». Це нормально для форку.
4. Натисни **⌘R** (Run).

### Варіант Б — через термінал (без підпису)

Найшвидше, якщо не хочеш чіпати Xcode. Локально зібраний застосунок запускається
без проблем із Gatekeeper (бо він не «завантажений» з інтернету).

```bash
just build-unsigned
open DerivedData/Build/Products/Debug/Pindrop.app
```

> `just build` (зі стандартним підписом) для форку **впаде**, бо в проєкті прописана
> чужа Team. Використовуй `just build-unsigned` або налаштуй свою Team у Xcode (Варіант А).

### Варіант В — попросити Claude Code

Якщо працюєш у Claude Code — просто відкрий папку й скажи:
> «Збери і запусти цей застосунок (`just build-unsigned`, потім `open` зібраний .app)».

У репозиторії є `justfile` та `CLAUDE.md`, тож агент усе зробить сам.

## 4. Перший запуск ⏳ (найважливіше)

Перший старт виглядає так — **це нормально, не закривай застосунок**:

1. **Дозволи.** macOS попросить доступ до **мікрофона** та **Accessibility**
   (для вставки тексту в інші застосунки). Надай обидва.
2. **Завантаження моделі (~3 ГБ).** Сплеш покаже `Downloading Whisper Large v3 Turbo…`.
   Потрібен інтернет; залежно від швидкості — кілька хвилин.
3. **Компіляція під Neural Engine (~2–3 хв).** Далі побачиш `Preparing Model…` /
   `Loading model…`. Перша компіляція великої моделі під ANE справді повільна
   (і повторюється після оновлення macOS). **Просто зачекай.**

> 🐢 Якщо здається, що «застрягло на Loading model…» — це майже завжди саме перша
> компіляція ANE. Наступні запуски стартують за секунди (кеш). Цей форк уже містить
> фікс, який не дає застосунку помилково перезавантажувати модель по колу.

## 5. Українська мова та AI-покращення

- **Мова інтерфейсу й диктовки:** меню Pindrop → **Settings → General** → вибери
  українську (інтерфейс і мову диктовки можна задати окремо).
- **AI-покращення тексту** (граматика/пунктуація/форматування): **Settings → AI Enhancement**.
  Працює локально через **Apple Intelligence** (macOS 26+), **Ollama** чи **LM Studio**,
  або через хмару (OpenAI/Anthropic/власний endpoint). Для приватного офлайн-сценарію
  бери Apple Intelligence або Ollama.

## 6. Часті проблеми

| Симптом | Причина / рішення |
|---|---|
| `No signing certificate "Mac Development"…` | Чужа Team у проєкті. Признач свою Team у Xcode (Варіант А) або збирай `just build-unsigned`. |
| Завис на `Loading model…` надовго | Перша компіляція ANE (2–3 хв) — зачекай. Якщо >10 хв — перезапусти; модель уже завантажена, кеш прогріється. |
| `"Pindrop" can't be opened` (Gatekeeper) | Стосується лише *завантажених* збірок. Локально зібраний застосунок цього не показує. За потреби: `xattr -dr com.apple.quarantine <шлях до .app>`. |
| Не вставляє текст у застосунки | Не надано **Accessibility**: System Settings → Privacy & Security → Accessibility → увімкни Pindrop. |
| Збірка дивно падає | `just clean && just build-unsigned`. |
